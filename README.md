# Darts – statikus játékverzió

Ez a verzió nem tartalmaz adminfelületet, bejelentkezést vagy backendet. A tábla adatai a `board.json` fájlból töltődnek be, ezért GitHub Pagesen önállóan működik.

## GitHub Pages

1. Hozz létre egy új GitHub repositoryt.
2. A ZIP tartalmát töltsd fel a repository gyökerébe (ne magát a ZIP-et).
3. GitHubon: **Settings → Pages**.
4. A **Build and deployment / Source** résznél válaszd a **Deploy from a branch** lehetőséget.
5. Branch: `main`, mappa: `/ (root)`, majd **Save**.

A `board.json` szerkesztésével később a hotspotok és feliratok tartalma kézzel is módosítható.
